# Death Predictor

Веб-приложение на базе **FastAPI** и **PyTorch** для прогнозирования стандартизованного по возрасту коэффициента смертности в США в зависимости от года, штата и конкретной причины заболевания.

---

## Какую задачу решает проект?
Проект автоматизирует анализ демографических и медицинских данных. С помощью глубокого обучения модель помогает оценить и спрогнозировать тренды смертности. Это позволяет выявлять аномалии по штатам и оценивать, насколько успешно медицина справляется с конкретными классами заболеваний с течением времени.

## Датасет и используемые данные - https://www.kaggle.com/datasets/willianoliveiragibin/causes-death-us
* **Источник датасета:** Данные взяты из открытых официальных источников США (CDC / National Center for Health Statistics).
* **Используемые признаки (Features):**
  * `Year` — Год фиксации данных (числовой признак, масштабированный с помощью `StandardScaler`).
  * `State` — Географический штат США (категориальный признак, закодирован через One-Hot Encoding).
  * `Cause Name` — Обобщенное название причины смерти (категориальный признак, закодирован через One-Hot Encoding).
* **Целевая переменная (Target / $y$):**
  * `Age-adjusted Death Rate` — Стандартизованный по возрасту коэффициент смертности (количество смертей на 100 000 населения).

## Архитектура нейронной сети
Для решения задачи регрессии используется полносвязная нейронная сеть (Многослойный перцептрон — MLP), написанная на **PyTorch**:

* **Входной слой:** Динамический размер `input_size` (зависит от количества колонок после One-Hot Encoding, ~60-70 признаков).
* **Скрытые слои:**
  * `Linear(input_size -> 128)` + Активация `ReLU()`
  * `Linear(128 -> 64)` + Активация `ReLU()`
  * `Linear(64 -> 32)` + Активация `ReLU()`
* **Выходной слой:** `Linear(32 -> 1)` без функции активации для предсказания непрерывной величины.

## Как обучалась модель?
* **Функция потерь (Loss):** `MSELoss` (Mean Squared Error).
* **Оптимизатор:** `Adam` с начальной скоростью обучения (learning rate) `0.001`.
* **Эпохи:** `250` итераций со случайным перемешиванием батчей (`shuffle=True`).
* **Размер батча (Batch Size):** `32`.
* **Разделение выборки:** 80% — обучение, 20% — валидация/тест (`random_state=42`).
* **Аппаратное ускорение:** Поддержка обучения как на CPU, так и на GPU (CUDA).

## Результаты работы
Модель показала высокую точность на тестовой отложенной выборке:

* **R² Score (Коэффициент детерминации):** `0.9994` — модель успешно объясняет 86.6% дисперсии данных.
* **MAE (Средняя абсолютная ошибка):** `3.00` — в среднем модель ошибается всего на 23.4 пункта коэффициента.
* **RMSE (Корень из MSE):** `5.41`.
